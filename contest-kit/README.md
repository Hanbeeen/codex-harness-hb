# 관리형 과제 환경용 준비물

제공된 Codex와 프로젝트를 유지하면서 요구 정리, 구현 검토와 본인 앱 검증에 사용하는 범용 지침임. 완성 앱, 정답, 개인 자료와 전역 설치기는 포함하지 않음. 공개 자료 사용과 다운로드가 허용된 환경에서만 적용하며 실제 과제 안내와 관리 정책을 우선함.

## 시작 요청

대회용 Codex 환경 준비는 루트 AGENTS.md와 README의 지침을 따름. 설치하는 Codex가 실제 버전과 경로를 확인하고 스킬, 훅과 플러그인을 각각 구성함. 이 폴더의 Python 설치기는 별도 프로젝트에 공통 문서만 복사하는 선택 도구임. 아래 요청은 이 폴더의 자료만 읽어 적용할 때 사용함.

```text
목표: 공개 준비물 중 이번 과제에 필요한 지침을 읽고 현재 프로젝트에 적용해줘.
맥락: https://github.com/Hanbeeen/codex-harness-hb 의 contest-kit 폴더, 실제 과제 안내 [위치], 제공 프로젝트 [경로]가 기준이야.
제약: 원문과 기존 지침을 먼저 읽어줘. 플랫폼이 지정한 클론 위치를 유지하고 이번 요청에서는 contest-kit의 자료만 적용해. 전역 설치기 실행, Codex 업데이트, 인증/모델 제공자/권한/플랫폼 관리 설정 변경, Computer Use와 원격 쓰기는 하지 마. 기존 파일은 덮어쓰지 말고 충돌을 알려줘.
완료 기준: 적용한 지침과 필요한 역할/요청문, 기존 실행/검사 방법, 실제 지원하지 않는 기능과 다음 구현 범위가 구분됨. 앱 구현이나 검증을 하지 않았다면 완료했다고 표시하지 마.
```

## 프로젝트 설치

제공 Python으로 install.py --project [제공 프로젝트의 절대 경로] --dry-run을 확인하고, 같은 명령에서 --dry-run을 빼 설치함. 기존 파일 내용이 다르면 덮어쓰지 않고 중단함. 설치 후 프로젝트 AGENTS.md와 .codex-harness/AGENTS.md를 직접 읽음. 기존 AGENTS.md 원본 백업은 해당 프로젝트 안에서만 보관하며 공개하지 않음.

제공 버전의 역할 지원을 확인한 뒤 --agents를 명시한 경우에만 프로젝트 .codex/agents에 역할을 배치함. 기본은 Markdown 순차 사용이며 이 레포의 루트 install.sh는 실행하지 않음.

## 적용 범위

1. [AGENTS.md](AGENTS.md)를 명시적으로 읽어 현재 세션에 적용함. 기존 제공 지침, 더 가까운 경로의 지침과 충돌하면 과제 안내를 따르고 충돌을 알림.
2. [과제 시작 요청](prompts/start-task.md)으로 원문과 실행 시작점을 확인함. 기본은 메인이 필요한 Markdown만 순차 사용함.
3. 지속 적용이 필요하면 기존 프로젝트 AGENTS.md를 읽고 필요한 규칙만 합침. 제공 파일과 설정을 통째로 덮어쓰지 않음. 자동 로딩은 새 실행 시 발견되는 특성이 있으므로 현재 세션의 직접 읽기와 구분함.
4. [.codex/agents](.codex/agents/requirements_analyst.toml)의 역할은 선택 사항임. 제공 버전의 지원이 확인되고 충돌이 없을 때 필요한 파일만 프로젝트의 .codex/agents에 복사함. 미지원이면 Markdown으로 대체하며 설정 변경이나 업데이트로 해결하지 않음.
5. qa-ui는 실제 사용 가능한 기존 Chrome DevTools MCP로 본인 앱만 확인함. 파일만 가져왔다고 브라우저 연결이나 역할 등록이 완료됐다고 쓰지 않음.

플랫폼이 지정한 클론 위치를 그대로 사용함. 원본과 대상이 같은 경우에는 이 폴더의 install.py를 실행하지 않고 필요한 자료를 직접 적용함. .git을 복사하거나 제공 프로젝트의 원격 주소를 바꾸지 않음. 개인 PC의 파일 업로드로 대체하지 않음.

## 필요한 자료 선택

한국어 출력에는 [공통 정책](korean-output.md)을 적용함. Python 설치기는 이 정책을 프로젝트 AGENTS.md 본문에 넣어 새 세션에서도 읽히게 함. 현재 세션에서는 설치 후 본문을 직접 읽음.

문자 혼입 검사는 제공 Python으로 필요할 때 실행함. 예를 들어 설치 후 `python3 -X utf8 -B .codex-harness/tools/check_korean_output.py 새문서.md`로 새 문서를 검사함. 채팅 표본은 같은 명령의 파일 인자 대신 `-`로 표준 입력을 전달할 수 있음. 보존할 원문만 `--allow-text '정확한 원문'`으로 허용하며 코드블록 전체를 제외하지 않음. 종료 코드 0은 미허용 문자 없음, 1은 검토할 문자 발견, 2는 실행 오류임.

이 검사는 원문을 바꾸지 않고 문법이나 자연스러움을 판정하지 않음. 긴 문서 윤문은 실제 제공되는 Codex용 humanize-korean이 있을 때 선택적으로 수행하고, 미지원이면 메인이 같은 보존 원칙으로 검토함. 모든 출력에 윤문 절차를 자동 실행하지 않음.

| 필요 | 사용할 자료 |
|:---|:---|
| 처음 시작 | [공통 지침](AGENTS.md), [시작 요청](prompts/start-task.md) |

| 요구와 사람 판단 기록 | [빈 양식](templates/README.md), [사람 검토](prompts/human-review.md) |

필요가 없는 역할, 문서와 검사를 모두 호출하지 않음. 제공 프로젝트와 현재 요구에 맞는 가장 단순한 구현을 우선하며 과설계를 피함.

## 금지와 조건

- git push는 대상/인자와 관계없이 금지함. 별칭, 스크립트, 다른 도구와 보조 역할로 원격 쓰기를 우회하거나 금지 확인용으로 실행하지 않음.
- 시험 원문, 데이터, 코드, 작성본, 작업 기록과 증거를 공개 레포나 외부 서비스로 보내지 않음. 원격 자료 읽기 허용을 송신 허용으로 해석하지 않음.
- 제공 Codex의 버전, 인증과 모델 제공자, 권한, 감독과 연결 프로세스를 보존함. 사용할 모델은 제공 목록 안에서 선택함.
- 이 폴더의 Python 설치기는 훅, 외부 플러그인, 원격 MCP와 새 API 키를 설치하지 않음. 네이티브 스킬, 훅과 플러그인은 루트 설치 지침에 따라 현장 Codex가 허용된 범위에서 별도로 구성함. 과제 내용이 외부 서버로 전송되는 경로를 만들지 않음.
- Computer Use를 사용하지 않음. qa-ui의 본인 앱 검증을 시험/감독/신분증/제출/후속 서술형 화면의 자동 조작이나 캡처로 확대하지 않음.
- 실제 실패는 수정 전에 허용된 서버 내 비공개 위치에 보존함. 도구가 없거나 수집이 실패하면 그 사실을 알리고 미실행으로 남김.
- 준비한 완성 결과물로 실제 과제 수행을 대체하지 않음. 확정 뒤 파일 수정과 후속 서술형의 AI/복사붙여넣기를 하지 않음.
- 반입에 사용한 저장소는 안내가 요구하는 시점까지 공개 상태를 유지함. 이 문서 자체를 주최 측의 승인이나 규칙 준수 인증으로 표현하지 않음.

## 확인 범위

Markdown과 TOML의 내용, 구문과 상대 링크를 확인한 준비물임. 실제 제공 버전에서의 역할 자동 등록, 도구 연결, 지침 준수와 탐지 성능은 별도 확인 대상임. 비공개 조사 자료와 원문 가이드는 포함하지 않음.

원본 qa-ui의 출처, 변경과 MIT 고지는 [NOTICE.md](NOTICE.md)에 유지함. 현재 Codex의 프로젝트 지침과 역할 형식은 [AGENTS 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [역할 문서](https://learn.chatgpt.com/docs/agent-configuration/subagents)를 참고함. 제공 버전의 실제 지원과 최신 문서의 기능을 동일시하지 않음.
