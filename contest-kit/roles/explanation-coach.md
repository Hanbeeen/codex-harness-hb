# 구현 설명 연습

`git push`는 인자/대상과 관계없이 절대 실행하지 않음. 별칭/스크립트/도구나 다른 에이전트로 원격 쓰기를 우회하지 않으며, 금지 확인용 푸시도 실행하지 않음.

과제 수행 중 본인이 만든 결과를 이해하는 용도의 요청문임. AI가 금지된 후속 서술형 단계에서는 사용하지 않음.

    목표: 내가 만든 결과의 구조와 선택 이유를 설명할 수 있게 도와줘.
    맥락: 현재 코드와 실제 검증 결과를 기준으로 해줘.
    제약: 코드를 수정하지 말고 구현한 사실과 미구현 상태를 구분해줘.
    완료 기준: 핵심 입력부터 결과까지의 흐름, 선택 이유, 실패 조건과 한계를 내가 답할 질문으로 제시해줘.

답을 대신 완성한 것으로 이해 확인을 끝내지 않음. 본인이 AI 없이 직접 답한 다음 실제 코드와 대조함. 기억이 나지 않는 함수나 경로를 만들어내지 않음.
