# 의사결정 기록

문서 구분: 재사용 빈 양식. 실제 작성본은 공개 준비물과 분리해 보관함.

구현을 바꾸는 결정만 짧게 남김. 실질적인 대안이 없으면 비교 표를 늘리지 않고 선택과 이유만 적음. 원문 요구를 바꾸는 권한을 이 기록에 부여하지 않음.

## [기준/검사 이름 또는 결정 제목]

- 기준과 근거: [요구 정리](prd.md)의 [기존 ID 또는 기준 이름], [선택을 바꾼 원문/실제 코드 위치/관찰]
- 결정 주체와 시점: [실제 선택한 사람 또는 승인된 위임 범위, 시점]
- 선택이 영향을 주는 결과: [사용 흐름, 데이터 또는 검증에서 달라지는 부분]

| 안 | 판정 | 이유와 감수한 한계 |
|:---|:---|:---|
| [채택안] | 채택 | [확인한 근거와 선택 이유, 남은 비용/위험] |
| [실제로 검토한 대안. 없으면 행 삭제] | 기각 | [같은 목적에 비춰 기각한 이유] |

- 미확정과 재검토 조건: [남은 가정, 어떤 답변/관찰이 나오면 다시 판단할지]
- 구현과 검증: [현재 상태](state.md)의 [같은 기준/검사 이름]
- 변경 이력: [앞선 결정이 있으면 당시 조건, 바뀐 근거와 현재 효력. 없으면 해당 없음]

새 결정은 위 묶음을 복사해 추가함. 선택이 바뀌면 앞선 이유를 지우지 않고 적용 조건과 바뀐 이유를 연결함. 구현 위치와 실행 결과 전문은 현재 상태나 원본 증거에 두고 중복하지 않음.
