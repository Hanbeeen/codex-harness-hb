# 제출물 확정 전 요청

과제 수행 단계가 끝나기 전에 사용함. 제출 버튼을 누르거나 후속 서술형 답변을 생성하는 요청이 아님.

```text
목표: 제출물 확정 전에 빠진 필수 조건과 현재 실패를 확인해줘.
맥락: 제출 조건 [원문], 최종 파일 [목록], 실제 검사 [결과], 남은 시간 [값]이 기준이야.
제약: 파일 수정 없이 필수 요구, 저장 상태, 실행 방법, 공개 자료 출처와 한계, 진행 중인 수정 작업을 대조해줘. 새 기능과 추가 도구 설치는 제외해줘.
git push와 동등한 원격 쓰기는 절대 실행하지 마. 제출/백업/동기화를 이유로 실행하거나 다른 주체에게 대신 요청하지 마.
완료 기준: 충족/미충족/미검증이 구분되고 종료할 작업과 사람이 확인할 최종 항목이 남아 있음.
```

코드 저장, 제출물 확정과 최종 제출 완료를 구분함. 모든 작성 주체가 멈췄는지 사람이 확인하고 최종 절차를 수행함. 후속 서술형에서는 이 요청문과 AI를 사용하지 않음.
