# 요구와 상태 정리 요청

과제 수행 중 원문과 실제 관찰을 연결할 때 사용함. 대괄호는 확인한 값으로 바꾸고 미확인은 그대로 표시함. 후속 서술형 단계에서는 사용하지 않음.

빈 양식과 보관 원칙은 [양식 안내](../templates/README.md)를 따름. 실제 작성본은 공개 준비물과 분리된 허용 비공개 위치에 두고 커밋하거나 외부로 전송하지 않음. 짧은 기존 기록으로 충분하면 새 문서를 만들지 않음.

## 요구 정리

```text
목표: 원문에 근거해 구현과 검증에 필요한 짧은 요구 정리를 만들어줘.
맥락: 안내 [위치], 제공 파일 [경로], 실제 받은 답변 [내용/출처 또는 없음], 기존 검사 [이름/ID 또는 없음]가 기준이야.
제약: 원문 요구와 출처를 보존하고 확정 사실, 질문, 가정, 비목표를 구분해줘. 받지 않은 답변과 새 필수 기능은 만들지 마.
작성 위치는 [허용 비공개 위치 또는 기존 기록]이며 공개 준비물의 빈 양식은 채우지 마. 새 문서가 도움이 될 때만 prd.md, decisions.md, state.md를 같은 폴더에 두고 기존 기준/검사 이름을 재사용해줘.
완료 기준: 각 필수 요구에 입력/사전 상태, 행동, 관찰 결과가 연결되고, 구현을 바꾸는 미확정과 원문 충돌이 표시됨. 작성한 사실을 구현 완료나 검증 통과로 쓰지 마.
```

[요구 양식](../templates/prd.md)은 출처와 예상 결과를 담음. 핵심 계산이나 필수 산출물을 바꾸는 미확정은 질문으로 남기고 답변 전에는 영향을 받지 않는 작업만 진행함.

## 원문과 후보 문서 대조

```text
목표: 후보 PRD를 원문과 실제 답변에 양방향으로 대조해줘.
맥락: 원문 [위치], 답변 [위치], 후보 PRD [위치]가 기준이야.
제약: 수정 없이 누락, 반대로 바뀐 조건, 출처 없는 확장, 미확정과 부적절한 완료 기준을 구분해줘. 취향을 필수 결함으로 만들지 마.
완료 기준: 중요한 항목부터 실제 근거와 달라지는 결과, 최소 수정 또는 질문이 연결되고 진행 가능한 범위와 보류할 부분이 나뉨.
```

문서 대조는 앱 실행 검증이 아님. 구현 범위를 정할 때는 [사람 검토](human-review.md)에서 예상 결과와 미확정을 함께 확인함.

## 선택 기록

```text
목표: 실제로 선택한 접근의 이유와 남은 한계를 짧게 남겨줘.
맥락: 요구 [비공개 기록 위치와 기준/검사 이름], 실제 선택 [안과 결정 주체], 검토한 대안 [내용 또는 없음], 근거 [원문/코드/관찰 위치]야.
제약: 결정과 승인을 지어내지 말고 채택/기각 이유를 확인한 근거에 연결해줘. 실질적인 대안이 없으면 비교를 늘리지 마.
완료 기준: 선택이 바꾸는 결과, 남은 가정과 재검토 조건이 구분되고 구현/검증의 현재 상태를 찾을 수 있음.
```

[선택 양식](../templates/decisions.md)은 원문을 대체하지 않음. 선택이 바뀌어도 이전 결정의 적용 조건과 이유를 지우지 않음.

## 상태 갱신과 인계

```text
목표: 같은 목표를 이어갈 수 있게 실제 작업 상태와 남은 실패를 정리해줘.
맥락: 요구 [위치], 선택 기록 [위치 또는 없음], 현재 코드/데이터 상태 [근거], 실제 검사 [명령/행동과 결과], 허용 증거 위치 [경로 또는 미확인]야.
제약: 실제 코드 위치와 구현 상태, 검증 통과/실패/미검증/미실행을 구분하고 출처와 로그 전체를 반복하지 마. 기존 실패와 검사 ID를 재사용해 최초 실패, 수정, 같은 조건의 재검증을 연결해줘.
받지 않은 답변과 실행하지 않은 검사는 채우지 말고 진행 중 수정 주체, 미수집 증거와 도구 실패도 보존해줘. 실제 실패는 수정/새로고침 전에 보존하고 증거 수집 실패는 즉시 알려줘.
완료 기준: 최신 코드에 적용되는 관찰과 과거 결과가 구분되고 다음 행동, 필요한 입력과 미확인 범위가 남음. 새 검사 없이 상태를 정리한 것만으로 통과 범위를 넓히지 마.
```

[상태 양식](../templates/state.md)에 명령, 작업 위치, 종료 코드와 실제 관찰을 연결함. 실패 증거는 허용 위치에만 보존하고 비밀값과 감독/제출 화면을 수집하지 않음. 증거 위치가 미확인이면 임의 경로로 저장하지 않음.
