# Codex Harness

대회에서 제공되는 Codex를 준비하기 위한 지침과 재료임. 별도 자동 설치기를 추가하지 않으며 설치를 수행하는 Codex가 실제 환경에 맞게 배치, 등록과 검증 방법을 정함.

## 전달받은 환경

- 제공 Codex 버전은 0.163임. 설치할 때 `codex --version`으로 다시 확인함.
- 클론 위치가 /home/user/project로 제한될 수 있음. 실제 위치를 확인하고 허용된 경로를 그대로 사용함.
- 스킬, 훅과 플러그인 관련 경로가 읽기 전용으로 보였으나 정확한 경로는 확인되지 않음. 전역 경로와 프로젝트 경로를 구분해서 확인함.
- 제공 전역 지침을 통째로 교체하는 방식은 사용하지 않음. 기존 지침, 인증, 모델, 권한과 감독 설정을 보존함.

## Codex에 전달할 요청

```text
이 레포의 AGENTS.md와 README.md를 읽고 대회용 Codex를 준비해줘. 실제 버전과 경로를 확인해서 필요한 스킬과 플러그인을 각각 설치하고, 환경에 맞는 훅을 만들어 연결해줘. 전역 지침은 보존하고, 실제 로딩과 실행을 확인한 항목과 제한 때문에 적용하지 못한 항목을 구분해서 알려줘.
```

## 설치 담당 Codex의 기준

1. 원문 과제 안내, 현재 작업 경로, 버전과 실제 쓰기 가능한 경로를 확인함. /home/user/project를 바꿀 수 있다고 가정하지 않음.
2. contest-kit/AGENTS.md와 korean-output.md를 읽어 현재 세션에 적용함. 지속 적용은 제공 지침을 보존하는 방식으로 필요한 규칙만 추가함.
3. 필요한 스킬을 Codex 0.163이 읽는 경로와 형식으로 배치함. 프로젝트의 .agents/skills도 후보로 확인하며, roles의 Markdown을 스킬이나 역할로 사용할 수 있음. 개인용 홈 경로가 박힌 파일은 그대로 복사하지 않음.
4. codex-home/plugins.txt를 설치 목록과 출처로 사용함. `codex plugin --help`로 제공 버전의 명령을 확인하고 플러그인을 각각 설치함. 설치 여부, 활성 상태와 추가 인증 필요 여부를 구분함.
5. codex-home/hooks.json과 reminder.json의 목적을 참고해 실제 경로에 맞는 훅을 작성함. 한국어 문구 점검과 작업 원칙 재확인을 연결하되 기존 훅을 보존함. 파일 생성 뒤 프로젝트 신뢰와 /hooks 승인을 확인함. 승인 해시를 직접 만들거나 신뢰 검사를 우회하지 않음.
6. 현재 세션에서 적용 지침을 직접 읽고, 새 세션의 스킬 목록과 훅 실행, 플러그인 도구 로딩을 가능한 범위에서 확인함. 파일을 복사한 사실만으로 적용 완료라고 보고하지 않음.

읽기 전용이거나 관리 정책이 막는 항목은 경로와 오류를 보고함. 권한 변경, 별도 CODEX_HOME, 새 인증이나 제공 도구 업데이트로 제한을 우회하지 않음. 미지원 스킬/역할은 Markdown 직접 읽기로 대체할 수 있지만 훅이나 플러그인까지 실행된 것으로 표시하지 않음.

고정 경로를 사용하는 자동 설치기는 포함하지 않음. 현장 Codex가 필요한 파일만 허용된 위치에 배치함.

## 플러그인 용도

| 플러그인/재료 | 사용 시점 |
|:---|:---|
| harness | commit, check, PR 초안과 변경 안내가 필요할 때. 시험의 원격 쓰기 금지를 우선 적용 |
| superpowers | 설계, 구현, 디버깅과 검증 흐름을 사용할 때 |
| andrej-karpathy-skills | 변경 범위를 줄이고 구현 가정을 점검할 때 |
| frontend-design | 새 화면을 만들거나 화면 구성을 다듬을 때 |
| context7 | 허용된 공개 기술 문서를 조회할 때. 시험 자료나 코드를 질의에 포함하지 않음 |
| chrome-devtools-mcp | 제공된 Node와 Chrome으로 본인 앱을 검증할 수 있을 때 |
| 한국어 출력 정책 | contest-kit/korean-output.md를 기본 지침으로 적용. 긴 문서 윤문이 필요하면 Codex용 humanize-korean을 별도로 검토 |

정확한 출처와 설치 식별자는 [plugins.txt](codex-home/plugins.txt)를 따름. 외부 플러그인의 현재 버전이나 인증 요구를 고정해서 가정하지 않음. fluent-korean의 Claude 전용 출력 스타일 등록과 Codex에서 한국어 지침을 읽는 동작을 동일시하지 않음.

## 디렉터리 역할

| 경로 | 역할과 사용 시점 |
|:---|:---|
| contest-kit/ | 대회용 공통 지침, 한국어 정책과 준비물. 시험 설치의 기본 자료 |
| codex-home/ | 개인용 전역 지침, 훅, 역할, 스킬과 Git 훅 원본. 시험에서는 필요한 내용과 플러그인 출처만 참고 |
| plugins/harness/ | commit, check, pr-draft, patchnote 스킬을 담은 플러그인 원본. 해당 기능을 설치할 때 사용 |
| .agents/plugins/ | 로컬 플러그인을 발견하기 위한 마켓플레이스 목록. 파일 존재와 플러그인 활성화는 별개 |
| docs/ | 설계와 AI 협업 설명을 위한 사전 연습 자료. 프로젝트 설치 대상이 아님 |
| .git/ | 저장소 이력과 원격 정보. 제공 프로젝트로 복사하지 않음 |

contest-kit 내부는 다음처럼 선택함.

- roles/: 요구 분석, 구현 검토, 검증, 화면 설계와 보안 역할. 역할 등록이 불가능하면 필요한 Markdown을 직접 읽음.
- prompts/: 과제 시작, 요구 정리, 검증과 확정 전 확인 요청. 해당 작업을 시작할 때 사용함.
- templates/: 요구, 상태와 결정의 빈 양식. 실제 기록은 허용된 비공개 위치에 작성함.
- ui-kit/: 화면 요구, 읽기 구조와 검증 체크리스트. 본인 앱의 화면을 설계하거나 확인할 때 사용함.
- tools/: 한국어 문자 혼입 검사기. 새로 작성한 파일이나 문구를 확인할 때 실행함.
- .codex/agents/: Codex용 역할 파일. 제공 버전의 역할 지원과 경로를 확인한 경우에만 사용함.

## 검증과 참고

설치한 스킬의 발견 여부, 훅의 실제 실행과 플러그인 도구 로딩을 현장에서 확인함. 한국어 문자 검사는 `python3 -X utf8 -B contest-kit/tools/check_korean_output.py 새문서.md`로 실행함. 개발용 테스트와 개인 PC용 설치/제거 스크립트는 포함하지 않음.

Codex 0.163의 [프로젝트 스킬 검색](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/ext/skills/src/host_roots.rs), [훅 로딩과 신뢰 검사](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/hooks/src/engine/discovery.rs)를 참고함. 최신 문서의 모든 기능을 제공 버전과 동일시하지 않음.

[설계와 AI 협업 설명 답안 템플릿](docs/post-task-answer-templates.md)은 사전 연습용임. 공식 기출이나 실제 수행 기록이 아님.
